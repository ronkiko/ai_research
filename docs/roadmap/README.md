# Roadmap tree

Новые patch-series документируются по
[четырёхуровневой координате](../versioning.md):

```text
release.branch.series.patch
```

Текущая долгоживущая линия:

```text
release 0
└─ branch main
   ├─ series 2 — текущая, приёмка открыта
   └─ series 3 — следующая, после приёмки series 2
```

Текущая серия:

- [0.main.2 — Единое тело Юки в мире новеллы](0/main/2/README.md)

Следующая заготовка:

- [0.main.3 — Social embodiment, escort and demonstration](0/main/3/README.md)

`docs/refactor/embodied-vn/` и зарегистрирован как `0.main.2` без переноса файлов.
