# CLAUDE.md

Кратко. Основная информация по проекту — в `README.md`. Прочитай его первым.

- Зонтичный исследовательский проект: игры как среды для изучения
  человекоподобного поведения ИИ. Суть и стек — в `README.md`.
- Активные компоненты (`gameserver/`, `gameclient/`, `gamelab/`, `gametable/`)
  независимы. У каждого свой детальный `README.md` и (при необходимости)
  `AGENTS.md`.
- **При работе внутри компонента приоритет у его локальных ридми/агент-файлов**,
  не у корневых. Решения одного компонента не переноси в другой.
- Стек: Python 3.10+, PyTorch (CPU), адаптер ИИ. Сейчас — только локальный
  обучаемый бэкенд; Ollama оставлен на будущее.
