# game2 — лаборатория управления в физическом мире

Первый этап: ручная проверка платформера. Нейросети, обучение, датчики и
оркестратор пока не реализованы; их устройство обсуждается отдельно.
Game1 не меняется, его правила не наследуются.

## Запуск

Python 3.10+ и графический рабочий стол:

```bash
cd game2
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python engine.py
```

- Удерживать **→**: разгон вправо, в том числе в воздухе.
- Нажать **↑**: прыжок с земли. Повторный прыжок в воздухе запрещён.
- **R**: новая попытка; **Esc**: выход.
- После отпускания вправо на земле действует торможение, в воздухе сохраняется
  горизонтальная скорость. В этой версии нет движения влево.

Игрок — квадрат 64×64. Начальная позиция x=100. Земля на y=360, яма
x=500…760 (260 пикселей), дно с шипами на y=584. Для проверки:
просто двигаться вправо — падение и DIE; разбежаться и прыгнуть перед
краем — приземление справа и SUCCESS. Успех требует приземления.

## Физика и время

`physics.py` независим от Pygame. `World.step(right, jump)` продвигает
симуляцию ровно на 1/120 секунды. `right` — удержание, `jump` — новое
нажатие. Гравитация 1800 px/s², импульс прыжка 700 px/s, предельная
горизонтальная скорость 340 px/s. Разгон 1800 px/s², торможение 1400 px/s².
Прыжок при максимальной скорости покрывает примерно 264 px на той же
высоте; ширина тела даёт дополнительное окно для приземления.

Отрисовка ограничена 60 FPS, физика использует аккумулятор времени и
фиксированный шаг 120 Hz. После задержки обрабатывается максимум 250 ms;
отброшенное реальное время видно в HUD. Это лабораторный цикл, **не гарантия
hard real-time**. Будущие дедлайны датчиков и политика опоздавших решений
ещё не реализованы. Обучение впоследствии можно запускать без отрисовки.

## Цветовое наблюдение

Игровое поле 1200×640, HUD расположен отдельно под ним. `render_world`
рисует чистую поверхность `observation`, которую можно будет передавать
датчикам. Текст и FPS в неё не попадают.

| Объект | RGB |
|---|---|
| Пустота | 255,255,255 |
| Земля | 0,0,0 |
| Игрок | 0,102,255 |
| Опасная поверхность | 255,0,0 |

Шипы — красная поверхность с белыми зубчатыми вырезами для человека.
Весь прямоугольник от y=584 — опасный объём; зубцы не выступают за него.
Физика использует геометрию, будущие датчики должны получать пиксели,
а не скрытые координаты. Датчиков в текущем этапе нет.

## События

Поверхности имеют свойство `damage`. Касание опасной поверхности выдаёт
ровно одно событие `die`, переводит `alive` в `False` и останавливает тело.
`step` возвращает события текущего такта; runner печатает их в stdout как
JSON Lines с номером попытки, например:

```json
{"event":"die","reason":"damage_surface","tick":213,"episode":1}
```

`success` однократно означает приземление за ямой, `reset` — ручной перезапуск.
После смерти симуляционные такты продолжаются, действия игнорируются до R.

## Проверка

```bash
python -m unittest -v
```

Проверяются устойчивость на земле, прыжок и приземление, управление в
воздухе, запрет двойного прыжка, однократная смерть, преодолимость ямы
с разбега и воспроизводимость одинаковых действий.
