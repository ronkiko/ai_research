# Console Configs

Data-only Console configurations. Map paths are resolved relative to each config
file.

- `server.json` is the canonical persistent realtime Console configuration.
- `realtime-smoke.json` and `unpaced-smoke.json` exercise the same fixed physics
  with different wall-clock pacing for tests.

Temporary graphical demo configs were removed together with the old graphical
Vision/demo shells. Human Screen hosting now belongs to the independent Screen
Server path rather than a Console demo launcher.
