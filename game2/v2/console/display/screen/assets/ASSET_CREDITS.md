# Screen Assets

These PNG files are the V2-owned runtime copies of the artwork from
`game2/assets/FreeCuteTileset/`:

- `BG1.png`, `BG2.png`, and `BG3.png` provide the layered background.
- `Tileset.png` provides the terrain cells used by the screen autotiler.
- `Decors.png` provides the `tree`, `bush`, and `ruin` decorations.

The source pack directory contains no separate license, credits, or README file.
The source files are kept unchanged; this note records the provenance of the
copies and the exact files used by the V2 screen renderer.
