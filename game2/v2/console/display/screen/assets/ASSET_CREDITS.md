# Screen Assets

These PNG files are V2-owned runtime copies of the screen artwork:

- `BG1.png`, `BG2.png`, and `BG3.png` provide the layered background.
- `Tileset.png` provides the terrain cells used by the screen autotiler.
- `Decors.png` provides the `tree`, `bush`, and `ruin` decorations.

The original source pack is not retained in the working tree. This note records
the exact files used by the V2 screen renderer.
