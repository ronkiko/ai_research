# 001 — Игровой клиент и базовая информация об игре

`game_v1` — прямой машинный игровой клиент лаборанта.

Он подключён через GameClient Host к авторитетному realtime-миру GameServer.
Мир продолжает работать независимо от скорости рассуждений лаборанта.

## Инструменты

Ожидаются MCP tools:

- `game_v1_health`
- `game_v1_describe`
- `game_v1_players`
- `game_v1_login`
- `game_v1_session`
- `game_v1_game_state`
- `game_v1_move`
- `game_v1_recent_events`
- `game_v1_logout`

Начинай с `game_v1_health`. Состояние `connected` у MCP само по себе не
доказывает готовность GameServer и GameClient Host.

Для актуальных игровых возможностей используй `game_v1_describe`, а не
предположения.

## Базовые свойства текущего клиента

Текущий публичный v1-контракт одномерен:

- координата мира: `x`;
- диапазон: `0..1000`;
- прямые команды движения: `left`, `right`, `stop`;
- движение остаётся активным, пока не будет изменено;
- мир realtime и не ждёт следующего вызова инструмента.

Если `describe` сообщает более новый контракт, доверяй ему.

## Наблюдение и управление

`game_state` — основной компактный снимок мира.

После управляющей команды проверяй фактическое состояние мира. Успешный ответ
MCP означает принятие команды, но не доказывает достижение игровой цели.

Для координации между клиентами используй bounded `recent_events`. Не
реконструируй отсутствующее скрытое состояние и не спамь одинаковыми командами.

`logout` завершает общую Host-сессию игрока; не используй его как безусловный
локальный cleanup, если другие подключённые инструменты ещё работают с этой
сессией.
