# 003 — Лаборатория: расширеные настройки

Это руководство описывает возможности `gamelab_v1`, которых нет у обычного
игрового клиента.

## Host-инстансы

Обычный `game_v1` использует свой Host по умолчанию:

```text
host_id = game-v1-default
host    = 127.0.0.1
port    = 17700
```

GameLab знает этот Host и использует его по умолчанию. Он принадлежит игровой
системе, а не лаборатории.

Для экспериментов лаборатория может создавать дополнительные обычные
GameClient Host-инстансы. Они запускаются на других локальных портах начиная с
`17701` и подключаются к тому же GameServer.

Доступные advanced tools:

- `gamelab_v1_host_list` — показать default Host и дополнительные лабораторные Host;
- `gamelab_v1_host_create(host_id)` — создать новый лабораторный Host;
- `gamelab_v1_host_delete(host_id)` — удалить лабораторный Host.

Попытка удалить `game-v1-default` возвращает `PERMISSION_DENIED`. Этот Host
создан игровой системой и не принадлежит лаборатории.

## Выбор Host

Игровые операции лаборатории принимают `host_id`. Если он не указан,
используется `game-v1-default`.

К выбранному Host относятся:

- `health`;
- `login`;
- `training_start`;
- `verify_start`;
- `run_start`.

Например, отдельный экспериментальный клиент можно подготовить так:

```text
host_create(host_id="experiment-2")
login(host_id="experiment-2", player_id="player2")
training_start(host_id="experiment-2", ...)
```

Этот Host является самостоятельным GameClient Host со своей игровой session.
Он может одновременно существовать рядом с `game-v1-default`, поэтому разные
Host могут войти разными игроками в один и тот же авторитетный мир.

Если указанного Host нет или он остановлен, лабораторная операция не
переключается на другой Host автоматически и возвращает ошибку.

Удаление собственного лабораторного Host завершает его игровую session и сам
Host-процесс. Это не затрагивает `game-v1-default`.
